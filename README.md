# ReleaseBoard

Panel web para seguir entregas, incidencias y estado de despliegues. Es un proyecto original construido con React y TypeScript como práctica de un flujo de trabajo de producto: navegar, filtrar información, paginar y registrar una incidencia.

## Incluye

- Rutas con React Router.
- Estado remoto local con TanStack Query y una mutación para crear incidencias.
- Búsqueda, filtro por estado y paginación funcional.
- Modal con validación básica.
- Interfaz responsive para escritorio y móvil.

## Tecnologías

React 19, TypeScript, Vite, React Router, TanStack Query y Lucide.

## Ejecutar localmente

```bash
npm install
npm run dev
```

Para generar el build de producción:

```bash
npm run build
```

## Contexto de aprendizaje

El proyecto toma como referencia temas del curso *React: De cero a experto* de Fernando Herrera, especialmente routing, manejo de estado, consultas y mutaciones, formularios y una UI de administración. El dominio, los datos y la implementación son propios.
